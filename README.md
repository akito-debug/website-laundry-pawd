# Cleanzy Laundry — Website & Order System

Website landing page dan sistem pemesanan online interaktif untuk **Cleanzy Laundry**. Didesain dengan tampilan modern, bersih, dan fully-responsive untuk memudahkan pelanggan melakukan pemesanan layanan laundry antar-jemput.

---

## 🌟 Fitur Utama

- **Landing Page Responsive**: Tampilan elegan yang nyaman diakses dari layar smartphone, tablet, maupun desktop.
- **Auto-Slide Carousel Layanan**: Banner slide otomatis (setiap 2 detik) dengan fitur *pause on hover* untuk membaca detail layanan.
- **Kalkulator Estimasi Biaya**: Fitur hitung instan estimasi total harga berdasarkan jenis layanan dan berat cucian (kg).
- **Form Pemesanan Detail (`order.html`)**: Form booking multi-step lengkap dengan pilihan layanan, varian aroma parfum, paket tambahan (addons), serta penentuan jadwal penjemputan.
- **Integrasi WhatsApp**: Otomatis merangkai ringkasan rincian pesanan dan mengarahkannya ke WhatsApp Admin (`+62 812-2521-2941`).
- **Sistem Kode Promo**: Masukkan kode promo `AKUCINTAAMIKOM` untuk mendapatkan diskon langsung 20%.
- **Daftar Jaringan Cabang**: Informasi lokasi cabang Cleanzy (Yogyakarta 1, Yogyakarta 2, Purwokerto, Surakarta, dan Ponorogo).

---

## 🛠️ Alat yang digunakan

- **HTML5**: Struktur halaman semantik & SEO-friendly.
- **CSS3**: Stylesheet tanpa framework external untuk kontrol desain maksimal (Flexbox, CSS Grid, CSS Variables).
- **JavaScript (ES6+)**: Logika kalkulator, carousel auto-slide, filter cabang, validasi voucher, dan generator pesan WhatsApp.
- **Google Fonts**: Typography Inter & Roboto.
